# 2차 QA — Notion 신버전 디자인 반영

기준: [10/11 첫 mvp QA](https://app.notion.com/p/3f6c510436ea800a9061ed15927c52e7)의 신버전·개선 디자인 캡처 및 변경 희망사항.

## 반영

- 홈: 좌측 메뉴, 우측 원형 프로필, 파란 예상세액 카드 내부의 금액 가리기, 두꺼운 확인 필요 비율 게이지.
- 홈: 중복 OCR·보관함 바로가기 대신 지금 확인할 항목, 신고 준비 요약, 신고 전 검토 버튼.
- 메뉴: 매입 보관함 / 매출 보관함 / 신고 전 검토 / 마이페이지, 아이콘과 회색 설명.
- 보관함: 흰색 카드·얇은 테두리, 거래명·날짜·금액·상태·상세 펼치기 및 거래별 행동 버튼.
- 보관함: 신고 기간, 전체·1~12월, 전체·확인 필요·분석 완료(매출은 확정) 필터 및 정렬.
- 보관함: 상단 건수 클릭으로 상태 필터 적용, 큰 분석·증빙 추가 버튼, 맨 위로 이동.
- 매출: 확정 거래만 합계에 포함. 공제 분석 기능은 매입에만 제공.
- OCR: 필드별 추출 여부, 미추출 개수와 항목명, 보관함·홈 이동, 재촬영·저장 후 추가 촬영/첨부.
- 마이페이지: 프로필 사진 변경, 사업자·과세 설정 이동, 계정 관리에는 로그아웃만 유지. 결제·플랜 UI 제외.
- 신고 전 검토: 기간별 실제 거래 건수, 예상세액, 미확정·공제 확인 항목 및 검토 체크리스트.
- 홈에서 보관함·신고 전 검토 이동 시 선택한 신고 기간 유지.

## 검증

- 프론트 빌드 통과, lint 오류 없음(기존 패턴 경고 4개).
- `node --test frontend/tests/review-state.test.mjs`: 3개 통과. 반기 경계, 확정 매출의 분석 제외, 중복 집계 및 삭제·다른 기간 제외 확인.
- 모바일 390×844에서 홈·보관함·OCR 확인 화면 점검. 보관함 페이지 가로 넘침 없음.
- 실제 QA 계정: 상태 필터, 9월/10월 필터, 메뉴 이동, 상세 패널, 삭제 확인창 및 취소 확인.
- 맨 위로 이동 후 scrollY=0 확인.
- OCR 필수값 누락 시 홈 이동 차단. 합성 증빙 7번의 추출 확인 저장 후 홈 이동 성공.
- 저장한 증빙은 거래 확정 전 확인 필요 항목으로 집계: 전체 8건, 확인 필요 7건, 준비 완료 1건. 거래 확정은 실행하지 않음.
- 홈 1기 선택 → 신고 전 검토 1기 유지 및 해당 기간 건수 확인.
- 화면 캡처: `round2-dashboard.jpg`, `round2-purchase.jpg`.

## 범위와 제약

- 프로필 사진은 사용자 ID별로 현재 브라우저에 저장. 서버 저장·기기 간 동기화는 미구현.
- 신고 기간은 기존 백엔드가 지원하는 2026년 범위 유지.
- 우측 로딩/새로고침 아이콘은 Notion에서 추후 고려 항목이므로 기존 새로고침 버튼 유지.
- 실제 OCR 인식 정확도 및 공제 판정·근거 정확도 검증에는 외부 OCR 설정과 분석 어댑터 연결이 필요.
- 이번 변경은 프론트엔드 중심이며 PDF 생성 작업 처리 및 세액 계산 엔진은 변경하지 않음. 실세액 및 PDF 생성은 이번 UI QA에서 추가 검증하지 않음.
- Notion 원문 및 체크박스는 수정하지 않음. 공유 PR: https://github.com/ecokdh/VAT-AI/pull/8 (대상 브랜치: integration/vat-ai-approved-rules).

### 이번 점검 중 수정

- 증빙 연결이 없는 미확정 수기 거래에도 거래 확인·저장 버튼 제공. 확정 전에 공제 분석 버튼이 나타나는 문제 수정.
- OCR 누락 안내를 “다음 항목을 직접 입력해 주세요: …”로 수정해 항목명에 따른 조사 오류 제거.
- OCR → 초안 → 확정 → 분석 단계별 세액 반영 회귀 테스트 추가. 격리된 테스트 DB 사용.

### 재검증 결과

- 전체 백엔드: 102 passed. 기존 datetime.utcnow 사용 관련 deprecation 경고 139건.
- 프론트: 빌드 통과, lint 오류 0/경고 4, 집계 테스트 3 passed.
- git diff --check 통과. 줄바꿈 변환 안내만 존재.
- 이번 최종 점검은 기존 브라우저 QA 결과에 코드 재검토와 전체 회귀 테스트를 추가한 것이며, 모든 화면을 새로 재촬영한 것은 아님.
- 실제 OCR/공제 분석 정확도, 프로필 사진 서버 동기화, 사업자 설정 세 구역 디자인은 완료 항목으로 공유하지 않아야 함.
