# 3차 QA — OCR 빠른 선택 및 신고기간 연동

기준: [10/11 3번째 QA 23:00](https://app.notion.com/p/3f6c510436ea80c7b42ee84ca07ad9d8)과 OCR 버튼 재터치로 닫힘·애니메이션 요청.

## 반영

- 하단 OCR 버튼을 누르면 버튼 위 작은 매입/매출 선택창 표시. 다시 누르면 닫힘. 바깥 클릭·Esc·다른 화면 이동도 닫힘.
- 180ms 투명도 및 240ms 이동/크기 애니메이션. 모션 감소 설정에서는 전환 생략. 닫힌 선택창은 키보드·접근성 탐색에서 제외하고, 열린 상태에서 OCR 다음 Tab은 매입 선택으로 이동.
- 선택 시 기존 빈 선택 페이지를 거치지 않고 방향을 지정한 촬영·첨부 화면으로 이동. 직접 `/capture` 방문 시의 기존 선택 화면은 경로 복구용으로 유지.
- 전체 메뉴에 로그아웃 추가.
- 사업자 형태(개인/법인)와 과세유형(일반/간이)을 별도 입력. 법인+간이 조합은 서버에서도 차단.
- 입력한 과세유형은 별도 저장하며 국세청 조회 결과를 덮어쓰지 않음. 불일치하면 신고기간 선택과 예상세액 계산 차단. 국세청 조회가 없으면 입력 정보로 기간은 안내하지만 예상세액은 계산하지 않음.
- 개인 일반: 1기/2기, 법인 일반: 1기 예정/확정·2기 예정/확정, 개인 간이: 연간. 정보 미입력 시 기간 선택 제한 및 설정 링크 제공.
- 홈·매입·매출·신고 전 검토에 공통 기간 선택 UI 적용. 사용자별 브라우저 세션에 선택 저장하고 URL의 유효한 명시 선택을 우선. 사업자 유형 변경 시 잘못된 이전 선택은 폐기.
- 신고기한·기간 범위·예정신고/고지 안내 제공. Q1은 1~3월, Q3는 7~9월. 확정 기간은 반기 전체 거래 기준이며 기납부세액 차감 전 추정치임을 표시.
- 서버 추정 계산에 Q1/Q3 범위 추가. 개인 계정의 임의 예정신고 요청은 현재 지원 범위 밖으로 차단.

## 검증

- 백엔드 105개 통과. 신규 검증: 분기 경계, 반기 집계, 국세청 값 보호, 법인+간이 차단, 법인정보 없는 예정신고 요청 차단, 새 DB 필드 마이그레이션.
- 프론트 테스트 6개 통과: 유형별 기간, 미입력 제한, 공유 기간/URL 우선순위, 유형 전환, 분기 경계 및 기존 집계 정책.
- 프론트 빌드 성공, lint 오류 0/기존 패턴 경고 4.
- 모바일 390×844 실제 브라우저: OCR 열기→재터치 닫기, Esc, 바깥 클릭, Tab 매입 포커스, 매출 촬영 연결, 가로 넘침 없음.
- QA 계정으로 법인 4개 옵션, 간이 연간, 개인 일반 2개 옵션 저장·전환 확인.
- 홈 1기 예정 선택→보관함→메뉴의 신고 전 검토로 이동해 선택 유지 확인.
- 메뉴 로그아웃→로그인 화면 확인 후 QA 계정 재로그인. 임시 사업자 형태·과세유형은 기존 미입력 상태로 복원. 실제 국세청 사업자정보나 거래는 변경하지 않음.
- 화면: [OCR 빠른 선택](round3-ocr-picker.jpg).

## 적용 및 범위

- 새 마이그레이션: `python -m alembic upgrade head`. 로컬 SQLite는 백업 후 적용하고 API·worker 재시작 완료.
- 사업자정보 미입력 계정은 먼저 마이페이지에서 형태·과세유형을 저장해야 신고기간별 건수를 볼 수 있음.
- 사업자정보가 없어 기간을 선택할 수 없을 때 홈·보관함·신고 전 검토의 기간별 건수를 0건으로 표시하지 않고 설정 안내를 표시.
- 소규모 법인 예정고지 대상 여부는 자동 확정하지 않고 안내. 고지서 조회·기납부세액 차감 및 특별 신고 케이스는 미구현.
- 법인 확정 화면은 반기 누계 추정치이며, 예정신고 실적/고지세액을 정산한 제출용 신고서가 아님. 예정 기간의 의제매입 한도 관련 정보가 부족한 경우 기존 엔진의 부분 계산/확인 필요 원칙 유지.
- 신고기한은 일반 일정. 개별 연장, 휴폐업, 과세유형 전환, 간이과세자 별도 신고 예외는 안내 대상으로 유지.
- 실제 OCR/공제 모델 정확도는 이번 UI·기간 연동 테스트 범위 밖.
- 3차 변경은 로컬 작업 상태이며 커밋·푸시는 하지 않음.
