## 사용 전 필요한 설정 및 범위

- 새 로고는 미제공이므로 텍스트 명칭만 반영했다. 취소선 처리된 PASS/전화번호 본인인증은 제외했다.
- 사업자 기본 과세유형은 기존 국세청 조회 결과를 사용한다. 마이페이지에는 가입 후 수정 기능을 유지한다.
- **2025년은 거래 조회를 지원한다.** 현재 계산 엔진은 2026년 규칙 전용이므로 2025년 예상세액은 `UNAVAILABLE`, PDF 생성은 비활성화한다. 2025년 세법 적용 엔진을 추가한 것은 아니다.
- 신고기간의 1기/2기 확정은 각각 1~6월/7~12월이다. 이를 잘못된 2분기/4분기 범위로 표시하지 않는다.
- OCR 상세 자동 추출은 원문에 명시된 라벨을 보수적으로 읽는다. 모든 품목의 자동 구조화나 정확도를 보장하지 않으며, 편집 가능한 품목/추가 항목과 원문을 제공한다.
- 최초 촬영 안내 상태는 서버의 계정에 저장한다. 기존 계정도 배포 후 첫 촬영 때 안내를 본다. 안내 상태 저장에 실패하면 다음 촬영 때 안내가 다시 나올 수 있다.
- ‘영구 삭제’는 기존 보관 정책에 따라 삭제 **요청을 기록**한다. 확인창/완료 문구에 이를 알리며 즉시 원본을 물리 삭제했다고 표시하지 않는다.
- 생성하는 PDF는 신고 지원용 예상세액 자료이며 정식 신고서나 홈택스 자동 제출 기능은 아니다.

## 메일 설정

`.env.example`의 다음 값을 실제 발송 서비스 정보로 채운 뒤 API를 재시작한다.

```dotenv
FRONTEND_URL=http://localhost:5173
SMTP_HOST=
SMTP_PORT=587
SMTP_USE_SSL=false
SMTP_USERNAME=
SMTP_PASSWORD=
SMTP_FROM=
```

587은 STARTTLS, 465는 `SMTP_USE_SSL=true`로 사용한다. 배포 시 `FRONTEND_URL`은 실제 HTTPS 서비스 주소로 바꾼다. 발송 서비스가 아직 없으므로 실제 메일 발송은 미검증이며, 미설정 시 사용자에게 준비 중 안내를 반환한다. 등록 여부에 관계없이 같은 요청 응답을 사용하고 이메일/IP별 요청 횟수를 제한한다. 재설정 토큰 원문은 DB에 저장하거나 API 응답/로그에 노출하지 않는다.

## 실행

```sh
python -m pip install -r requirements-dev.txt
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 별도 터미널
python -m app.jobs.worker
# 별도 터미널, frontend 디렉터리
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

새 마이그레이션은 `b72c4e91f630`이며 비밀번호 재설정 토큰, 계정별 안내 여부, 세션 버전, OCR 상세 저장 필드를 추가한다. 로컬 QA는 승인받은 SQLite를 사용했다. PostgreSQL 실환경 회귀 검증은 별도 필요하다.
