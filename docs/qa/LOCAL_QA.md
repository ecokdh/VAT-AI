## 남은 검증·제약

1. `.env`에 CLOVA URL/키가 비어 있어 실제 OCR 인식 품질 검증은 미완료입니다. 업로드·원본 표시·수동 입력·저장은 검증했습니다. 인식 결과가 없는데 인식 완료로 표시하던 안내를 수정했습니다.
2. `DEDUCTION_ANALYZER` 미설정 상태입니다. 기본 분석기는 모든 거래를 검토 보류 처리합니다. 가능·불가능 판정과 법령·판례 근거의 실제 정확성은 모델 어댑터와 근거 데이터가 연결된 뒤 검증해야 합니다. 가짜 근거를 추가하지 않았습니다.
3. 국세청 검증은 사업자번호의 상태·과세유형 조회입니다. 상호·대표자·개업일 진위확인이나 공제 가능성 검증은 아닙니다.
4. PostgreSQL 실행 및 해당 DB에서의 마이그레이션, 실제 카메라 촬영은 이번 SQLite QA에 포함되지 않았습니다.
5. 목표 OCR·보관함 디자인 스크린샷은 아직 제공되지 않았으므로 픽셀 단위 디자인 비교는 미완료입니다. 전달된 스크린샷은 실행 구성 확인에 반영했습니다.
6. PDF 생성은 이번 QA 범위에서 검증하지 않았습니다.
